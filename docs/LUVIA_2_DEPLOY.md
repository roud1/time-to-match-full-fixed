# Luvia 2.0 — выкладка на Render

Ветка `luvia-2` → `main`. Render собирает сервис `time-to-match-web` из `main` по `render.yaml`;
команды сборки и запуска **не меняются**.

## Что меняется для пользователей

- Новый дизайн Luvia на сайте и в приложении (Android-оболочка Capacitor и PWA на iPhone).
- Название вкладки, PWA и иконки — «Luvia» (короткое имя на домашнем экране тоже «Luvia»).
  Домены, package id приложения, имена БД и сервисов на Render остаются прежними.
- Убраны фиктивные функции: процент совместимости, «прочитано», голосовые/фото-заглушки,
  платное «+24 часа» без оплаты, бесплатный Premium/буст на клиенте, выдуманные цены и
  «14 дней бесплатно», «режим в тени», выдуманные уведомления, пустой экран «Реклама».
- Появились: удаление аккаунта в настройках (по паролю, `DELETE /api/me`), смена пароля
  через письмо, реальные уведомления с сервера.
- Исправлен баг: отправка сообщения в мэтче возвращала 500 (`FOR UPDATE` на LEFT JOIN).

## База данных

Новых миграций нет. При сборке, как и раньше, выполняются `db:migrate` и `db:seed-demo`.
Сид теперь ставит тестовым анкетам `photo_verified = false` (без поддельных значков проверки).

## Переменные окружения (Render → Environment)

| Переменная | Нужна? | Зачем |
|---|---|---|
| `STRIPE_SECRET_KEY`, `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY`, `STRIPE_WEBHOOK_SECRET` | для оплаты | Без них Premium показывает «Оплата пока недоступна», цена не выводится. |
| `STRIPE_PREMIUM_CENTS`, `STRIPE_VIP_CENTS` | нет | Цена подписки в центах (по умолчанию 1499 / 2999 USD). Эту же цену видит пользователь. |
| `ALLOW_UNPAID_FREEZE_PACKS` | нет | `1` — вернуть старое поведение: пакеты заморозок начисляются **бесплатно**. По умолчанию в продакшене покупка пакетов отключена (оплаты для них нет). |
| `NEXT_PUBLIC_ADSENSE_PUBLISHER_ID`, `NEXT_PUBLIC_ADSENSE_SLOT_ID` | нет | Без них экран рекламы между анкетами не показывается. |

Важно: пока Stripe не настроен, буст включается бесплатно (это реальный буст, так было и раньше).

## Шаги

1. Открыть PR `luvia-2 → main`, дождаться проверок CI.
   Известно заранее: e2e-тесты с регистрацией упираются в лимит 8 регистраций / 15 мин с одного IP
   и в подтверждение email — это было и до редизайна.
2. Merge PR. Render автоматически начнёт деплой (`autoDeploy` из `main`).
3. Дождаться статуса **Live** в Render → Events (сборка ~5–8 минут на free-плане).
4. Проверить на телефоне (iPhone — после «Обновить» страницы; PWA с домашнего экрана может
   держать старую версию до перезапуска):
   - главная → «Начать» / «Войти», вход, лента свайпов, мэтч, чат (отправка сообщения);
   - профиль → Premium (без цены, если Stripe не настроен), настройки → удаление аккаунта видно;
   - иконка и название «Luvia» при установке PWA («На экран Домой» нужно добавить заново,
     чтобы iOS подтянула новую иконку).
5. Android-оболочка (`mobile/`) грузит сайт, поэтому дизайн обновится без новой сборки APK.
   Название «Luvia» и иконки Luvia для самого APK уже лежат в `mobile/` (`appName`,
   `resources/res`), но появятся на телефоне только после новой сборки APK.
   `appId` (`com.timetomatch.app`) не менялся — обновление ставится поверх старого приложения.

## Откат

Render → сервис → **Events** → у предыдущего удачного деплоя «Rollback», либо revert merge-коммита
в `main`. Схема БД не менялась, откат безопасен.
